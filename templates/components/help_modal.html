管理员仪表盘 / Admin Dashboard

统计概览卡片 / Statistics Cards

仪表盘顶部的四个彩色卡片展示了系统的核心数据概览：

  • 用户统计：显示已注册和已导入的用户数量，点击可跳转至用户管理页面。
  • 考试统计：显示考试总数及各状态（进行中、已关闭、草稿、未开始）的数量。
  • 培训统计：显示培训总数、总签到次数和今日签到次数。
  • 访谈统计：显示访谈总数，点击可跳转至访谈管理页面。
考试管理列表 / Exam Management List

考试列表中的每一行都提供了完整的考试管理操作：

  • 推送：设置考试有效期并通知考生参加考试。
  • 编辑：修改考试名称、时长、阅卷人和题目（仅草稿状态可编辑题目）。
  • 拷贝：复制整个考试（包括题目），生成新考试。
  • 删除：支持软删除（可恢复）和永久删除。
  • 批量导出PDF：导出所有考生的成绩单（ZIP压缩包）。
考生考试状态 / Candidate Exam Status

选择考试后，可查看每位考生的考试状态并进行管理：

  • 分配/取消分配：为考生分配或取消考试任务。
  • 重置：重置考生考试状态，允许考生重新参加考试。
  • 查看得分：点击详情查看考生的答题情况。
导出报告 / Export Report

支持两种导出模式：

  • 精确筛选：通过国家、培训、考试、日期等条件精确筛选数据导出。
  • 综合筛选：支持多选培训和考试，一次性导出多份报告。

培训管理 / Training Management

创建与编辑培训 / Create & Edit Training

点击「新增培训」按钮创建培训，填写名称、国家和有效期。

  • 编辑名称：点击行内的编辑按钮修改培训名称。
  • 编辑有效期：在编辑模式下可直接修改开始和结束时间。
  • 国家：培训关联的国家决定哪些用户可以看到该培训。
推送培训 / Push Training

点击「推送」按钮，设置签到有效期并选择推送对象：

  • 推送全部：通知所有国家匹配的已注册用户。
  • 定点推送：选择指定用户进行推送。
  • 通知：推送后用户会收到邮件通知。
签到表头录入 / Header Template

为培训的签到表设置表头信息（支持双语），可针对不同国家设置不同模板。

  • 表头字段：培训名称、项目编号、地点、语言、对象、组织部门等。
  • 国家模板：点击「表头录入」可为特定国家设置独立模板。
查看签到状态 / View Sign-in Status

点击培训名称或「签到人员」按钮，查看该培训所有学员的签到状态。

  • 状态筛选：可按已签到、待签到、需重新签名等状态筛选。
  • 操作：可分配培训、取消分配、强制重新签到。
培训照片 / Training Photos

点击培训行内的照片图标进入照片管理界面。

  • 上传：选择培训后上传照片，自动添加日期水印。
  • 查看：按培训分组展示照片，支持大图预览。
  • 删除：管理员可删除任意照片，普通用户仅能删除自己上传的。
培训-考试绑定 / Training-Exam Binding

点击培训行内的「▶」展开图标，管理该培训绑定的考试。

  • 绑定考试：选择考试绑定到培训，学员签到后将自动分配绑定考试。
  • 配置：设置及格分数、是否自动分配、是否必修。
  • 补分配：为已签到但尚未分配的学员补分配考试。

考试管理 / Exam Management

创建与编辑考试 / Create & Edit Exam

有两种方式创建考试：

  • 导入Word：上传符合格式的Word文档，自动解析生成考试。
  • 拷贝考试：从已有考试复制，快速创建新考试。
考试状态 / Exam Statuses
  • 草稿：考试创建中，未推送，可编辑所有内容。
  • 未开始：已推送，但未到开始时间，考生不可进入。
  • 进行中：考试正在进行，考生可进入答题。
  • 已关闭：考试已结束，不可修改题目，可查看成绩。
考试推送 / Exam Push

点击「推送」按钮，设置考试时间和阅卷人：

  • 有效期：设置考试开始和结束时间。
  • 时长：设置考试时长（分钟）。
  • 阅卷人：指定阅卷人姓名。
  • 考生：选择推送的考生列表（支持搜索和筛选）。
成绩与详情 / Scores & Details

点击「详情」查看考生成绩列表，支持：

  • 查看答题详情：查看每道题的考生答案和得分。
  • 导出PDF：单个或批量导出考生成绩单。
  • 强制重置：允许考生重新参加考试（保留原成绩）。
已删除考试 / Deleted Exams

点击「已删除考试」按钮查看软删除的考试记录。

  • 恢复：将软删除的考试恢复为正常状态。
  • 永久删除：彻底删除考试（仅当无关联成绩记录时）。

用户管理 / User Management

添加与编辑用户 / Add & Edit User

支持两种方式添加用户：

  • 手动添加：填写用户信息，设置角色和权限范围。
  • 批量导入：下载模板，填写后上传导入用户。
用户列表操作 / User List Operations
  • 搜索/筛选：按姓名、邮箱、国家、库房等条件筛选用户。
  • 导出Excel：导出当前筛选条件下的用户清单。
  • 重置密码：生成新密码并发送至用户邮箱。
  • 标记离职/复职：管理用户在职状态，离职用户将无法登录。
角色与权限 / Roles & Permissions
  • 普通用户：仅可参加考试和培训签到。
  • 管理员：可管理指定国家的用户、培训、考试等。
  • 超级管理员：拥有所有权限，可创建管理员。
  • 开发者：拥有最高权限，可访问所有功能和数据。
已删除用户 / Deleted Users

点击「已删除人员」按钮查看软删除的用户记录。

  • 恢复：将用户恢复为正常状态。
  • 永久删除：彻底删除用户（不可恢复）。

访谈管理 / Interview Management

创建访谈 / Create Interview

创建访谈的步骤：

  • 选择考试：从已有考试中选择题目来源。
  • 选择用户：选择参与访谈的学员。
  • 题目数量：设置每位学员的访谈题目数量。
  • 预览：预览每位学员的访谈题目。
访谈状态 / Interview Statuses
  • 草稿：访谈创建中，可编辑所有内容。
  • 未开始：已保存，未到开始时间。
  • 进行中：访谈正在进行，学员可参与。
  • 已关闭：访谈已结束，可查看结果。
强制访谈 / Force Interview

对未完成访谈的学员发起强制访谈：

  • 触发：在访谈详情页点击「强制访谈」按钮。
  • 效果：学员将收到新的访谈任务，有效期2小时。
  • 批量强制：支持同时为多位学员发起强制访谈。
查看访谈结果 / View Interview Results

点击访谈列表中的「详情」按钮查看：

  • 答题详情：查看每位学员的答题情况。
  • 统计：显示答题数量和正确率。
  • 重新抽题：为学员重新生成访谈题目。

库房管理 / Warehouse Management

库房操作 / Warehouse Operations
  • 添加库房：输入库房编码、名称和类型。国家代码会自动从库房ID提取。
  • 编辑库房：修改库房信息。
  • 删除库房：支持软删除（可恢复）和永久删除（需无关联用户）。
  • 批量导入：下载模板，填写后导入库房信息。
国家关联 / Country Relation

库房编码的前2位自动识别为国家代码（如 NP001 → 尼泊尔）。系统会根据库房的国家自动分配用户。

隐私声明管理 / Privacy Management

版本管理 / Version Management
  • 创建版本：输入版本号、标题、内容和更新日志。
  • 编辑版本：修改已存在的版本内容（非活跃版本）。
  • 激活版本：激活后，所有用户需重新确认隐私声明。
  • 删除版本：仅可删除非活跃版本。
用户确认状态 / User Confirmation Status

点击统计卡片查看用户确认情况：

  • 已确认：已确认当前隐私声明的用户。
  • 未确认：尚未确认当前隐私声明的用户。
  • 确认率：显示当前版本的确认百分比。

培训照片管理 / Photo Management

上传照片 / Upload Photos
  • 选择培训：从下拉列表中选择要上传照片的培训。
  • 选择文件：支持从相册选择或直接拍照。
  • 水印：自动在照片左下角添加日期和培训名称水印。
  • 数量限制：每个培训最多可上传50张照片。
查看与管理 / View & Manage
  • 照片墙：按培训分组展示照片，支持展开/折叠。
  • 筛选：按培训名称或季度筛选照片。
  • 预览：点击照片大图查看，支持前后翻页。
  • 删除：管理员可删除所有照片，普通用户仅可删除自己上传的。
